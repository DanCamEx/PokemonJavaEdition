Pokémon Java Version. created by Daniele Camelin and Simone Bovolenta
Questo gioco simula una battaglia tipica di Pokémon riprendendone le sue meccaniche!

ISTRUZIONI

Questo repository contiene i file sorgente del gioco. Per essere eseguito è necessario pullare il progetto in un git all'interno di Eclipse. 
Non è prevista una build dotata di un jre eseguibile.

Il gioco è stato creato ad unico scopo didattico e con l'obiettivo di superare un corso universitario. Non ci arrestate please.
